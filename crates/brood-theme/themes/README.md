# Bundled Helix themes

The complete Helix 25.07.1 theme collection is bundled here: 172 files from
[`runtime/themes`](https://github.com/helix-editor/helix/tree/25.07.1/runtime/themes),
plus `default.toml` and `base16_default.toml` from Helix's root `theme.toml` and
`base16_theme.toml`. The loader's build script embeds every `.toml` file, so
there is no separate hand-maintained discovery list or Helix runtime dependency.

Files are unmodified. Author and attribution comments, the upstream theme
README (`README-helix.md`), and the complete upstream `licenses/` directory are
preserved. Helix's MPL 2.0 license is in `LICENSE`; Ashen's upstream MIT license
is also retained in `LICENSE-ashen`.
