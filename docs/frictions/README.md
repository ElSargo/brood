# Design Frictions

This directory records evidence that the current design may have an oversight,
mismatch, unresolved tradeoff, or recurring source of friction. These are
inputs to design work, not accepted target changes and not general task lists.

Each note should state:

- the target or boundary involved;
- the observed tension and its evidence;
- the practical cost or risk;
- any known constraints;
- the design question that remains open.

When design work resolves a friction, update the applicable page in
[[../targets/README]], then move the implementation outcome to
[[../progress/README]] or delete the friction if it has no lasting value.
