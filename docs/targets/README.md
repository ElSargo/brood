# Design Targets

This directory describes the product and architecture Brood is working
towards. A target is an intentional design contract. It can be ahead of the
implementation.

Do not edit these pages merely because implementation differs from them. A
target changes only when design work intentionally adds, replaces, or refines
the desired state. Record delivery facts in [[../progress/README]] and
design-level tensions in [[../frictions/README]].
