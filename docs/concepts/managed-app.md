# Managed App

A managed app is an external native application whose windows or surfaces Brood tracks, places, and preserves as part of a session.

The current implementation's concrete managed-app path is a hosted Wayland app connected to Brood's nested Wayland compositor.

Use `hosted Wayland app` when specifically discussing that implementation. Use managed app for the product concept.
