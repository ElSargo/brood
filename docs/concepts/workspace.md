# Workspace

A workspace is the product-level Manifold environment. It contains sessions, saved presentation preferences, configuration, and shared project context.

Use `workspace` when talking about the umbrella environment. Use [[session]] when talking about one isolated group of panes, programs, agents, cwd, and capabilities.
