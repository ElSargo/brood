# Implementation Progress

This directory is durable implementation working memory. It records milestones,
verification evidence, failed approaches, temporary constraints, and other
developments that future work should not have to rediscover.

Progress notes describe what happened. They do not redefine the desired state.
Link to the applicable page in [[../targets/README]] and put unresolved
design-level mismatches in [[../frictions/README]]. Remove incidental command
transcripts and machine-local paths unless they are necessary to reproduce or
interpret evidence.
